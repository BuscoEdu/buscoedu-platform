# Implementación · Ronda 3 NaIA + UX + Universidades B2B

**Fecha:** 2026-09-20  
**Rama:** `feature/naia-r3-20260920`  
**Repositorio:** `BuscoEdu/buscoedu-platform`

## 1) Objetivo de la ronda

Corregir una regresión crítica de NaIA en producción (fallback genérico permanente) y completar ocho frentes de UX/arquitectura solicitados:

1. Fix resiliente de despliegue en `AgenteExecutor`.
2. `Puedes continuar con` debajo del input.
3. Chat limpio sin filtros/chips.
4. Franja disclaimer entre experiencia y footer.
5. Resultados móvil full-screen con cierre prominente.
6. `/explorar` heredando base de `/naia` con resultados prioritarios.
7. Nueva landing `/universidades` B2B completa con formulario real.
8. Nueva sección de guía operativa en `/admin/ia/guia`.

## 2) Cambios críticos aplicados

### 2.1 Fix crítico NaIA (root cause)

**Archivo:** `lib/agentes/AgenteExecutor.ts`

- Se mantuvo lectura de `despliegue_id` desde `configuracion_snapshot`.
- Si no existe en snapshot, ahora hay fallback a despliegue activo más reciente (`updated_at DESC`; fallback técnico a `actualizado_en`).
- Si no hay despliegues activos, se conserva error semántico `sin_despliegue_asignado`.
- Se agregaron comentarios en español en bloques clave de `resolverConfiguracion`.
- En `ejecutar()`, el contexto de ofertas solo se inyecta si hay datos reales útiles.

### 2.2 NaIA UX (chat/resultados)

**Archivo:** `components/naia/NaiaSearchExperience.tsx`

- Sugerencias `Puedes continuar con` movidas debajo del input (desktop + móvil).
- Se eliminaron chips/filtros del chat; ahora solo aparecen en resultados.
- Modal de resultados móvil full-screen (`z` superior), con botón sticky `Volver al chat` y bloqueo de scroll global.
- Cuando modal de resultados móvil está abierto, se oculta header global.
- Se añadió franja disclaimer entre experiencia y footer.
- Se mantuvo cálculo de altura robusta en desktop.

### 2.3 Footer sin disclaimer duplicado

**Archivo:** `components/layout/Footer.tsx`

- Se retiró el párrafo disclaimer del footer.
- El texto ahora vive en franja contextual de NaIA.

### 2.4 /explorar hereda la lógica de /naia

**Archivo:** `app/explorar/page.tsx`

- Página simplificada para usar `NaiaSearchExperience layoutVariant="explorar"`.
- Hereda conversación/contexto/fallback/parsing de `/naia`.
- Ajusta proporciones para priorizar área de resultados.

## 3) Nueva página B2B /universidades

**Archivos:**
- `app/universidades/page.tsx`
- `components/universidades/UniversidadesLanding.tsx`
- `app/api/universidades/contacto/route.ts`

Implementado:

- Landing completa de 13 secciones (hero, problema, solución, flujo, valor entregado, condiciones comerciales, marca, beneficios, modalidades, medición, piloto, FAQ acordeón y formulario final).
- H1 exacto solicitado:
  - `Conecta con estudiantes que están preparados para tomar una decisión`.
- CTA principal repetido estratégicamente (hero, mitad y final) + sticky móvil.
- FAQ desplegable (acordeón) con 11 preguntas.
- Formulario conectado a endpoint real (`/api/universidades/contacto`) para guardar en Supabase.
- Aviso de privacidad incluido en formulario.
